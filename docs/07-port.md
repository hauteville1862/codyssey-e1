# 07 포트 매핑 및 브라우저 접속 증거

## 명령어 요약

| 명령어 | 설명 |
| --- | --- |
| `docker run -d -p 호스트포트:컨테이너포트 --name 이름 이미지` | 컨테이너 실행과 동시에 포트 매핑 (06번에서 이미 수행) |
| `curl http://localhost:호스트포트` | 터미널에서 응답을 텍스트로 확인 (브라우저 스크린샷의 보조/대안) |
