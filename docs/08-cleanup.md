# 08 커스텀 이미지 삭제 및 정리

## 명령어 요약

| 명령어 | 설명 |
| --- | --- |
| `docker ps -a` | 중지된 컨테이너까지 포함해 정리 대상 컨테이너를 확인 |
| `docker rm 컨테이너` | 이미지를 참조하는 컨테이너를 먼저 삭제 |
| `docker rmi 이미지이름[:태그]` | 빌드한 커스텀 이미지를 삭제 |

> 이미지 빌드/컨테이너 실행은 [06 이미지 빌드](06-image-build.md), 포트 매핑 접속 검증은 [07 포트 매핑](07-port.md)에서 이미 끝낸 뒤, 그 결과물(컨테이너·이미지)을 정리하는 마지막 단계

### 8-1. 커스텀 이미지 삭제
